# 易经数字占卜

基于傅佩荣三位数易经数字占卜法的交互式算卦工具。Apple 风格设计，纯前端实现。

## ✨ 功能

- 🎲 **三位数起卦**：输入三个任意三位数（100–999），严格按先天八卦取余规则自动计算本卦、变卦、动爻
- 📐 **运算拆解可视化**：分步展示每步除法过程、余数、对应卦象
- ☯ **卦象展示**：6 爻 SVG 竖排渲染（上爻在上，初爻在下），动爻红色标注，本卦与之卦并排对比
- 📖 **卦辞详解**：卦辞 → 彖传 → 大象传 → 六爻小象传 → 六爻爻辞全览，动爻高亮
- 🔍 **专家详解**：64 卦全部含傅佩荣《易经入门》、曾仕强《易经的智慧》、倪海厦《天纪》三家详细解读
- 🎯 **四项断语**：事业工作、身体健康、财运、姻缘感情四大维度专项分析
- 🔄 **之卦（变卦）**：之卦由来说明（哪爻阴阳反转）→ 卦辞 → 彖传 → 大象传 → 小象传 → 六爻爻辞 → 趋势走向分析
- ⚠️ **起卦禁忌**：心神不定不占、不反复占问（至少间隔三个月）、不诚不占、违法悖德不占、酒后不占、子时不占、极端天气不占、三位数只测小事（重大决策建议大衍筮法）
- ☯ **先天八卦方位图**：乾上坤下、离左坎右，中心太极阴阳鱼

## 🚀 使用方式

浏览器直接打开 `iching-divination.html`，无需任何后端或依赖。

## 📚 数据来源

- 卦辞、爻辞、彖传、象传原文及白话翻译：**中华书局《周易》**（杨天才、张善文译注）
- 64 卦大象传 + 384 条小象传：《周易》通行本原文
- 专家解读参考：
  - **傅佩荣**《易经入门》
  - **曾仕强**《易经的智慧》
  - **倪海厦**《天纪》

## 🎨 技术栈

- 单文件 HTML + CSS + JavaScript，零外部依赖
- Apple 风格设计系统（SF Pro Display / PingFang SC、浅灰背景 `#f5f5f7`、圆角卡片、`cubic-bezier` 动效）
- SVG 渲染卦爻和八卦方位图
- 数据库与页面分离架构，便于维护和扩展
- 响应式布局，适配桌面和移动端
