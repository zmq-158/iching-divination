# 易经数字占卜

基于傅佩荣三位数易经数字占卜法的交互式算卦工具，纯前端单文件实现，无需任何后端依赖。

## ✨ 功能

- 🎲 **三位数起卦**：输入三个任意三位数（100–999），严格按先天八卦取余规则自动计算
- 📐 **运算拆解可视化**：分步展示每步除法过程、余数、对应卦象
- ☯ **卦象展示**：6 爻 SVG 竖排渲染，动爻红色标注，本卦、变卦并排对比
- 📖 **卦辞详解**：通行本周易卦辞 + 彖传 + 大象传 + 小象传（六爻象辞）+ 六爻爻辞全览
- 🔍 **专家详解**：整合傅佩荣、倪海厦、曾仕强三家解读
- 🎯 **四项断语**：事业工作、身体健康、财运、姻缘感情
- 🔄 **之卦（变卦）**：完整之卦卦辞、彖传、六爻爻辞 + 趋势走向分析
- ⚠️ **起卦禁忌**：传统占卜规范参考（含大衍筮法建议、三月间隔规则）
- ☯ **先天八卦方位图**：乾上坤下、离左坎右，中心太极阴阳鱼

## 🚀 使用方式

直接在浏览器中打开 `iching-divination.html` 即可使用。

## 📚 数据来源

- 卦辞、爻辞、彖传、象传原文及白话翻译：中华书局《周易》（杨天才、张善文译注）
- 64 卦大象传 + 384 条小象传：通行本周易原文
- 专家解读参考：傅佩荣《易经入门》、倪海厦《天纪》、曾仕强《易经的智慧》

## 🎨 技术实现

- 单文件 HTML + CSS + JavaScript，零依赖
- Apple 风格设计系统（SF 字体、浅灰背景、圆角卡片）
- SVG 渲染卦爻和八卦方位图
- 响应式布局，适配移动端

## ⚖️ 理性提示

易经占卜为中华传统文化遗产，本工具仅供文化参考与心理指引，不构成任何形式的绝对宿命判定。本质不是算命预知，是借助易经原文哲理帮自己理性梳理选择、规避风险，仅供参考。
