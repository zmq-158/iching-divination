# 易经数字占卜

基于傅佩荣三位数易经数字占卜法的交互式算卦工具，纯前端单文件实现，无需任何后端依赖。

## ✨ 功能

- 🎲 **三位数起卦**：输入三个任意三位数（100–999），严格按先天八卦取余规则自动计算
- 📐 **运算拆解可视化**：分步展示每步除法过程、余数、对应卦象
- ☯ **卦象展示**：本卦卦名、卦象符号、动爻标示、变卦参考
- 📖 **卦辞·彖传**：通行本周易原文 + 中华书局白话译文
- 🔍 **专家详解**：整合傅佩荣、倪海厦、曾仕强三家解读
- 🎯 **四项断语**：事业工作、身体健康、财运、姻缘感情
- ⚠️ **起卦禁忌**：传统占卜规范参考
- ☯ **先天八卦图**：SVG 绘制，上乾下坤，中心太极阴阳鱼

## 🚀 使用方式

直接在浏览器中打开 `iching-divination.html` 即可使用。

## 📚 数据来源

- 卦辞、爻辞、彖传原文及白话翻译：中华书局《周易》（杨天才、张善文译注）
- 专家解读参考：傅佩荣《易经入门》、倪海厦《天纪》、曾仕强《易经的智慧》

## ⚖️ 理性提示

易经占卜为中华传统文化遗产，本工具仅供文化参考与心理指引，不构成任何形式的绝对宿命判定。
